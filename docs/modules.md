# Modules

## Safety Triage

Classifies user input into red, yellow, or green safety states. Red states should route the user toward emergency services or immediate safe support.

## Incident Intake

Collects the minimum context needed for documentation: location, jurisdiction, date, police status, injuries, property loss, and immediate concerns.

## Timeline Builder

Builds a chronological list of events from Chinese recall. Each event includes description, type, sequence, and certainty.

## Follow-Up Interview

Asks targeted, non-leading questions to fill missing details and resolve contradictions. Users can mark uncertainty instead of being forced into false precision.

## Evidence Checklist

Identifies potentially useful evidence and gives safe preservation guidance, such as asking a venue manager to retain CCTV before it is automatically deleted.

## Statement Generation

Produces neutral English drafts for police, doctors, universities, insurers, and support services. Users must review generated text before using it.

## Support Guidance

Suggests local support pathways, victim support services, compensation preparation, and professional help. It avoids legal conclusions or exact outcome predictions.
