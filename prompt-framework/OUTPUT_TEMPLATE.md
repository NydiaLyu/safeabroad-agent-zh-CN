**Incident Report**
-   **Date/Time**: [Date] at approximately [Time]
-   **Location**: [Location]
-   **Description**:

I felt threatened and frightened. I am not entirely certain of the suspect's exact height, but they appeared to be around [Height].

## Multi-Language Generation Notes | 多语言生成说明

1. **Generate all requested document languages** | 生成所有请求的文书语言
2. **Maintain consistent facts across all languages** | 在所有语言中保持事实一致
3. **Use appropriate uncertainty markers for each language** | 为每种语言使用适当的不确定性标记
4. **Provide reference translation in interaction language if different from document language** | 如果交互语言与文书语言不同，提供参考翻译
5. **Label each section clearly with language indicators** | 用语言标识清晰标注每个部分
